B-School Engagements — photo gallery

Open index.html in any browser (works offline, no server needed).
Views: Gallery (drag the year rail on the right to scrub), Timeline (drag / scroll / arrow keys / play), Calendar (hover a month to flick through, click to open).

Structure
  photos/    full-size images  (named YYYY-MM_place_n.jpg)
  thumbs/    small copies used for the grid (same file names)
  photos.js  the list — one line per photo:
             {"file": "photos/2026-01_iim-kozhikode_1.jpg", "date": "2026-01", "title": "IIM Kozhikode", "w": 769, "h": 965}

To add photos: drop the image in photos/ and a thumbnail in thumbs/, then add a line to photos.js.
date can be "YYYY-MM" or "YYYY-MM-DD". Order in the file doesn't matter — the page sorts by date.
Or just send this zip back to Claude with the new photos and dates.
